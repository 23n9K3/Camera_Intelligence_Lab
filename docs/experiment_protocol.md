# Camera Intelligence Lab 实验协议

## 记录与输入

每次实验以唯一 `experiment_id` 关联任务、输入 Artifact、执行配置、随机种子、工具调用、Agent 时间、IQ 记录、Trial 和报告。模拟数据记录相对照度、CFA、布局、缺陷坐标及模拟转换增益。上传采集数据需保留曝光、增益、温度、光源和采集顺序。用四种 CFA、不同位深、低照和饱和场景复验测量。

## Sensor 方法

- 每个像素对 N 帧求均值和样本方差。时间噪声为像素时间方差空间平均后取平方根，单位 DN。单帧仅支持像素分布、剖面及候选坏点。
- DSNU 为暗场均值图空间样本方差减去均值估计中的时间方差项（每像素时间方差均值除以帧数），下限截断到零后取平方根。当前整体 DSNU 保留行列结构和异常点的贡献。
- PRNU 使用平场均值减去匹配暗场均值。剔除饱和、热和死点，在四个 CFA 相位上分别扣除平/暗均值估计的时间方差，再除以各相位平均光响应的平方。对四个相对方差取平均、开根号，乘 100 变成百分比。需要平坦照明，照度梯度或镜头渐晕会影响结果。
- 热像素阈值为暗场中位数加上 8 倍稳健 MAD 标准差估计或满幅 4% 中较大者。死像素为同 CFA 相位中暗校正响应低于中位数 15% 的坐标。坐标采用零基 (x, y)。
- 行列噪声统计暗场均值图的行/列均值向量与总体标准差。该结果包含固定行列偏置与残余估计噪声。
- PTC 在固定增益、温度、均匀稳定光源条件下按曝光分组，每档采集至少两帧。横轴为暗校正平均信号 DN，纵轴为该档平均像素时间方差 DN²。实现用至少三个低于 85% 范围且剪裁率小于 1% 的不同信号点拟合。仅在斜率为正、截距通过筛查且 R² ≥ 0.9 时输出 DN/e⁻。电子数是 DN 除以增益，数值估计需依赖暗场、响应线性和已知照明条件。
- 饱和信号取均值达到 `saturation_fraction` 且至少 5% 采样达到白电平的最低曝光档暗校正均值。电子饱和容量仅在转换增益有效时估计。DR 采用该信号除以最低可辨识信号。后者为重复暗场 RMS 时间噪声乘以 `minimum_snr`，默认 1，再做 20log10。系数和饱和门限在 `configs/evaluation.yaml`。

详见 [EMVA 1288 概述与标准下载](https://www.emva.org/standards-technology/emva-1288/)。

## ISP 与 IQ 方法

- RAW 先减黑电平并归一化。坏点处理使用同 CFA 相位的中值阈值，边缘和纹理可能被过强校正损伤。径向增益模拟阴影校正，推荐实采平场校准。融合序列需要同 CFA、布局与尺寸；曝光时间必须为正，按上传顺序与图像对应。
- PSNR 为 −10log10(RGB 代码值 MSE)，峰值 1；一致图像对应正无穷，记录的 JSON 值为空并附方法说明。SSIM 对 RGB 通道取平均。两指标需共享尺寸与对齐，数值受比较的输出编码影响。
- ΔE00 分别解码候选和参考的 Gamma、转换到 sRGB，再到 D65 Lab，计算像素级 CIEDE2000 均值。真实图卡应用还应考虑曝光、参考白和颜色空间的校准。
- MTF50 对已选择的线性斜边 ROI 做梯度质心定位和直线拟合，采用垂边 4× 分箱形成 ESF，求差分 LSF、加 Hamming 窗，计算归一化 FFT 并做差分响应修正。从 Nyquist 以下首次下降穿过 0.5 的点插值。输入斜边可以是独立试样；该值属于试样对应的 Artifact。无采样覆盖、斜率越界、低对比或频率交叉越界时值为空。参见 [Burns 等人的 e-SFR 测量方法](https://library.imaging.org/admin/apis/public/api/ist/website/downloadArticle/ei/34/9/IQSP-357)。
- IQ 空间噪声取已声明均匀 ROI 中输出代码值的亮度标准差。图像 SNR 为 ROI 亮度均值/样本标准差的 20log10 值。Sensor SNR 用暗校正平场均值与平场时间噪声。两种 SNR 须按方法与单位分别解释。
- 优化只使用有效的 ROI 噪声、参考 SSIM 与 ΔE00。UI 上开启单独 Gamma/WB/锐化/降噪模块才能使对应搜索参数作用于输出。基线改善量的正数代表目标方向上的改善，负数代表退化。

## 实验与消融矩阵

| 实验 | 固定条件与比较组 | 可检验结论及指标 |
| --- | --- | --- |
| Agent 协作 | 共享 30 个任务、数据种子和搜索预算。Single 仅规划；Single + Tools 由 Supervisor 做路由，后续依照默认执行策略；Multi-Agent 由 Supervisor、Experimenter 和 Reviewer 决定路由、实验计划与追加测量 | 核验路由命中率、工具选择与成功率、任务产物验收、指标可追溯率、执行时间、在线 Token。Mock 默认共享算法及参数，在线协作需另外核验模型决策与复测分支 |
| Sensor 缺陷 | 固定曝光与 ROI，多种种子比较正常、热、死、行、列、DSNU、PRNU 注入；再用实采暗平场复验 | 热/死以标签算精确率和召回率；行列与 DSNU/PRNU 测注入强度扫描、误差及误报 |
| ISP 参数搜索 | 对同一对齐场景比较默认、Random Search、NSGA-II、Agent focus + NSGA-II。共享搜索边界、初始化、Wall time 与 Trial 数；比较采样时优先给足多代预算 | 报告逐目标差值、Pareto 分布和运行时间。用独立场景复评推荐配置。若噪声改善伴随色差上升，记录取舍 |
| Agent 消融 | Supervisor + ISP，加入 Sensor，再加入 IQ，再加入 Optimization，最后以完整数据验证与 Report 路径运行 | 比较可验证读数、坏点召回、指标覆盖、结论是否能追溯、任务完成率、总运行时间。用例与预算固定，明确记录组件关闭后不可测的值 |

核心基准运行器会实际比较三种 Agent 架构。默认、随机和 NSGA-II 可分别使用固定 `ISPConfig`、`Task(sampler="random")` 和 `Task(sampler="nsga2")`。多种子强度扫描、独立场景复评与五级消融是协议中的后续实验，尚未执行。记录每行的数据集 / seed / 配置 / 参数 / 指标 / 耗时 / experiment_id。每个报告的实验数据以 SQLite 记录和实际文件为准。

### 判定与复现

- Task Success 按预期路由、工具成功、任务级断言和报告实存共同判断。
- Diagnosis Accuracy 定义为路由正确率；Tool Selection Accuracy 以实际成功执行所需工具的用例比例计；Execution Success Rate 以所有工具调用尝试为分母。
- Grounding Rate 以有效 IQ 输出为分母，核对 SQLite 读数和输入 Artifact；未适用值记录为空。Mock token 为空。
- 运行器使用同一组 *已经生成* 的输入 Artifact 和配置执行三个分支。短预算、小规模模拟与冷启动顺序会影响时间。解释架构延迟时应改变运行顺序、重复测量并报告分布。
- 先跑 `pytest -q`，然后 `python scripts/run_demo.py` 与 `python scripts/run_agent_benchmark.py`。在线模型验证使用 `--live` 以及已配置的 API Key。
